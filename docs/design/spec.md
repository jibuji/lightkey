# 前端设计规范（design/spec）

- 状态：已拍板（D14；存储类型定案 v2，2026-08-15）
- 关联：高保真原型 [prototype](prototype/index.html)（可交互、可截图评审）
  · 工具链：自研 UI 设计工具 + agent_browser 预览截图 + doubao-seed-2.1-turbo
  视觉评审 + lavish-axi 船长评审面（D1/D2 已定，不装第三方设计 skill）

## 1. 目标与原则

- **安全工具的气质**：可信、克制、清晰。不炫技；信息层级服务于「用户知道
  自己能看到什么、什么被保护」。
- **默认暗色**：V1 只做暗色主题（安全工具夜间/聚焦场景），tokens 结构化以便
  未来扩展浅色。
- **零知识可见化**：UI 明示「存储端看不到你的数据」；解锁/锁定状态全局可见。
- **流程极简**：解锁 ≤2 步、条目复制 ≤2 击、授权审批 ≤1 击（+倒计时）。

## 2. 设计 Tokens

### 2.1 色彩

暗色基底 + 单一高亮品牌色（teal），语义色克制使用。

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg-0` | `#0F141A` | 应用底色（近黑蓝灰） |
| `--bg-1` | `#161B23` | 面板/卡片 |
| `--bg-2` | `#1D242F` | 悬浮/选中底色 |
| `--bg-3` | `#26303D` | 按压/输入框底 |
| `--border` | `rgba(255,255,255,.08)` | 分隔线、描边 |
| `--fg-0` | `#E6E9EE` | 主文本 |
| `--fg-1` | `#98A2B0` | 次级文本 |
| `--fg-2` | `#5C6672` | 弱化/占位 |
| `--brand` | `#2DD4BF` | 主品牌（teal），主按钮/焦点/品牌图形 |
| `--brand-strong` | `#14B8A6` | hover 态 |
| `--accent-blue` | `#38BDF8` | 信息/链接/图标辅助 |
| `--danger` | `#F87171` | 删除、拒绝、危险 |
| `--success` | `#4ADE80` | 成功、允许 |
| `--warning` | `#FBBF24` | 警告、恢复码 |

品牌渐变：`linear-gradient(135deg, #2DD4BF, #38BDF8)`（品牌图形/解锁动画点缀）。

### 2.2 字体与排版

- 家族：`system-ui` 栈 + 中文（PingFang SC / Microsoft YaHei）+ 等宽
  `ui-monospace`（密钥值、恢复码、命令）。
- 字号：`--fs-xs 12px` · `--fs-sm 13px` · `--fs-md 14px` · `--fs-lg 16px` ·
  `--fs-xl 20px` · `--fs-2xl 28px`。
- 行高：1.5（正文）/ 1.3（标题）。字重：400 正文、600 强调、700 标题。

### 2.3 间距 / 圆角 / 阴影 / 动效

| Token | 值 |
|-------|-----|
| 间距 | 4 · 8 · 12 · 16 · 24 · 32（`--sp-*`） |
| 圆角 | `--r-sm 6px`（输入/按钮）· `--r-md 10px`（卡片）· `--r-lg 16px`（弹窗/品牌） |
| 阴影 | `--shadow-1`（卡片，1px 边 + 弱投影）、`--shadow-2`（弹窗，强投影） |
| 动效 | 150ms ease（hover/focus）、240ms ease（弹窗/页面切换）；尊重 `prefers-reduced-motion` |
| 层级 | `--z-card 10` · `--z-dialog 100` · `--z-toast 200` |

## 3. 组件库（V1 清单）

| 组件 | 规格要点 |
|------|----------|
| 主按钮 | brand 底、白字、`--r-sm`；hover=brand-strong；禁用=降透明+禁点击 |
| 次级按钮 | 透明底 + border；hover=bg-2 |
| 危险按钮 | danger 底（删除/拒绝） |
| 图标按钮 | 32×32、bg-2 hover、圆形（复制/眼睛/更多） |
| 文本输入 | bg-3 + border、focus 品牌描边 2px（键盘可达） |
| 密码字段 | 值用等宽字体 + 圆点遮罩；眼睛按钮切换明文；「复制」图标按钮 |
| 卡片 | bg-1、`--r-md`、`--shadow-1`、border |
| 列表项 | 图标(类型) + 名称 + 副行（username/域名）；hover=bg-2；选中=brand 左边条 |

| 空态 Empty | 图标 + 一行文案 + 主操作按钮 |
| 侧栏 Sidebar | 64px 图标栏（条目/规则/设置/审计页切换）+ 底部锁定按钮 |
| 顶栏 Topbar | 搜索框 + 同步状态点 + 同步按钮 |
| 分段控件 | 列表/网格、筛选 Tab |

## 4. 存储类型定义（存储类型定案 v2，2026-08-15）

产品定位：只存**无法与别人分享的重要私密内容**。所有条目一律**真加密存储**——四类类型（含笔记、文件）与登录/密钥使用一致的加密强度与机制（零知识，存储端看不到明文）。

定案类型清单（四类）：

| 类型 | 字段定义 | 说明 |
|------|----------|------|
| 登录 login | 账号 + 密码 + 网址 | 无歧义 |
| 笔记 note（Markdown） | 名称 + Markdown 文本 | **轻量 Markdown 编辑**：编辑区内**语法高亮**，不做预览、不做所见即所得；不是旧版"名称+备注"空壳 |
| 密钥 secret | 名称、密钥值、用途/备注、可选过期时间 | 各类 key / API key / token（明文短文本 + 附属信息） |
| 文件 file | 名称、备注、大小、类型 + **加密附件** | 元数据 + 加密附件（文件本体独立加密存储）；单文件上限 **50MB** |

- **统一加密原则**：所有类型（含笔记、文件）真加密存储，与登录/密钥同等加密强度与机制。
- 列表副行与筛选规则见 §6.2；新建类型选择见 §6.3。
- 已砍类型：**收藏**（用途模糊，与定位不符，V1 不提供）。

## 6. 关键流程

### 6.1 解锁 / 锁定

- 解锁：居中品牌图形（teal 渐变圆角方块）→ 主密码输入 → 「解锁」主按钮；
  次级入口「用 Windows Hello 解锁」（已信任设备，见 [recovery.md](recovery.md) §4）
  与「用恢复码恢复」。错误提示不区分「密码错/库未建」
  （[ipc.md](ipc.md) §3 语义在 UI 的体现：统一文案）。
- 锁定：侧栏底部锁定按钮 → 立即回解锁页；锁定动画不拖沓。

### 6.2 条目列表与搜索

- 列表项 = 类型图标 + 名称 + 副行（登录→账号 · 笔记→片段 · 密钥→用途或脱敏值 · 文件→大小/类型）。
- 搜索：名称/用户名/域名，300ms 防抖；搜索命中高亮关键词。
- 空态：无条目 → 引导「添加第一条」；搜索无结果 → 「未找到，按回车新建」。

### 6.3 条目详情 / 编辑 / 新建

- 详情：字段分组（登录信息 / 自定义字段 / 附件）；密码字段遮罩 + 复制
  （复制后 Toast「已复制，30 秒后自动清除」，[browser-fill.md](browser-fill.md) 同款行为）。
- 编辑：同表单（名称/类型切换/字段增删）；保存走 CAS（冲突时提示
  「条目已被其他设备修改」并提供「覆盖/取消」）。
- 新建：类型选择（登录/笔记/密钥/文件）→ 表单 → 保存。

### 6.4 规则管理页（M2）

- 规则列表：项目目录 + 命令 + key 名 Tag 集合 + 删除。
- 新建规则：项目目录选择器 + 命令输入 + key 名多选（仅显示已授权 key 名，
  [authorization-gate.md](authorization-gate.md) §2）。
- 提示条：「规则保存在加密库内，随库同步」。

### 6.5 审批弹窗（M2）

- 触发：`lk inject -- ...` 未命中白名单。
- 内容：启动者图标/名称 · 项目目录 · 命令（等宽、脱敏）· 请求的 key 名 Tag 集 ·
  **倒计时环形（30s，默认拒绝）** · 「允许本次」「拒绝」。
- 超时自动「拒绝」+ 弹窗关闭 + 审计；键盘 Esc = 拒绝。

### 6.6 设置 / 审计 / 恢复

- 设置：安全（自动锁定时间、生物识别宽限开关）、同步（BYO URL、轮询间隔
  15s~24h）、审计保留（默认永久）。
- 审计页：事件流（时间/启动者/目标/命令摘要/结果 Tag）；只读，无密钥值。
- 恢复：`lk init`/重置向导展示恢复码（等宽大字、一次性、含校验字符分组）。

## 7. 文案与可访问性

- 文案基调：直接、诚实。含「三通道全丢 = 数据不可恢复」的如实说明
  （[recovery.md](recovery.md) §1），不写安慰性承诺。
- 键盘可达：全组件 focus 环可见；弹窗 Esc 关闭；列表方向键导航。
- 对比度 ≥ 4.5:1（fg-1 仅用于大字号）；禁用态不只用颜色表达（加图标/文案）。
- 动效尊重 `prefers-reduced-motion`。
